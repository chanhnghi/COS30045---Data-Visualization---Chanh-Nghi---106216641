ABOUT / THE PROJECT

Useful stories start with honest data.

Wattwise is a small learning prototype for COS30045 Data Visualisation. It brings a real TV registration snapshot into a clear, interactive website while we develop a broader question about Australian energy use.

W⚡

01 / PURPOSE

Built to ask better questions.

This first version lets visitors ask whether TV screen size is related to labelled annual energy consumption, and how the picture changes by technology or brand. It is an exploratory tool, not a recommendation engine.

When a stronger Assignment 1 dataset and angle are selected, the data and story can be updated without rebuilding the basic site structure.

02 / THE METHOD

What went into this view.

01

Source

A temporary television registration CSV named tv_2026_02_15.csv, captured on 15 February 2026.

02

Selection

The chart uses records marked “Available,” sold in Australia, with plausible numeric screen size and annual kWh values. Screen size is converted from centimetres to inches.

03

Encoding

Position on a shared scale shows screen size and annual kWh. Filters support comparisons without distorting the axes.

04

Limits

Registration status is not live store availability. Labelled yearly energy is a standardised value; actual household use and electricity cost vary.

03 / RESPONSIBLE USE

Make the workings visible.

For the class exercise, this website uses three HTML pages, one shared CSS file, and vanilla JavaScript for the FAQ, calculator, and data view. No external JavaScript library is required.

OpenAI Codex assisted with planning, visual design, implementation, and debugging. The README documents that assistance so the work can be reviewed and explained during the exercise demonstration.
